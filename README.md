# SMC 기술·생산관리 시스템 (P1)

## 바로 사용
`SMC_system.html` 을 더블클릭하면 브라우저에서 실행됩니다. (설치 불필요, 데이터는 브라우저에 저장)
- 데이터 백업: 기준값·이력 > 백업(JSON 내보내기/가져오기)

## 개발
```
npm install
npm run dev     # 개발 서버
npm test        # 계산엔진 테스트
npm run build   # dist/index.html 단일 파일 생성
```

## 범위
물탱크 처방 중심. 제품·처방은 화면에서 계속 추가. 처방(승인·버전) → 설정값 계산 → 배합지시서 → 생산일지 → 로트·라벨.
임시 가정: CBA308S 단가 8,400, 보관온도 상한 30°C (기준값 화면에서 수정).
